# Jetson Nano Projects

This repository contains my Jetson Nano learning and AI development projects.

## Structure
- `src/` – Python source code (AI, inference, utilities)
- `notebooks/` – Jupyter notebooks for training/experimentation
- `models/` – Saved ONNX/TensorRT models
- `data/` – Input data, images, and test files
- `scripts/` – Bash scripts, setup scripts
- `logs/` – Program outputs and detection logs

## Branches
- `main` – stable production-ready code
- `dev` – experimental development
